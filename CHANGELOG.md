## [1.0.0] — 2026-05-12

### Added
- Offline player with support for all major audio and video formats
- Downloader powered by yt-dlp — supports YouTube, SoundCloud, Vimeo, and 1000+ sites
- Upgradable download engine (yt-dlp update without app reinstall)
- Live preview — inline ad-free playback from supported URLs
- **Duo** — real-time playlist sync over WebRTC for long-distance listening
- **Duo Offline** — nearby device sync via Wi-Fi Direct (no internet required)
- Modern, minimal UI optimized for one-handed use
